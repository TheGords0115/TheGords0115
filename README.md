# Olá, eu sou o Gustavo Camargo

CTO na **QSUP Automações** e estudante de Sistemas de Informação (UniFasam), em Goiânia/GO.
Coloco em produção agentes de IA, e-commerces, integrações e dashboards para empresas de varejo, serviços e eventos.

## O que eu construo

- **Agentes SDR e de atendimento no WhatsApp**: multiagente, memória de longo prazo e passagem para vendedores (TypeScript, Node.js, API da Anthropic, n8n, Redis)
- **Checkout para Shopify com 3D Secure**: Pix, parcelamento e frete, criado para reduzir chargebacks (Node.js, Pagar.me/Stone, Docker)
- **E-commerce**: tema Shopify autoral (Liquid, JavaScript) e sites WordPress (PHP)
- **Dashboards** de tráfego pago e vendas para clientes (React, TypeScript, Supabase, Vercel)
- **CRM**: front-end e modelagem de banco de dados (React, Fastify, Prisma, PostgreSQL)
- **Integrações** com Mercado Livre, Bling e Melhor Envio
- **Infraestrutura** com Linux e Docker
